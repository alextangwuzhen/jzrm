# JZRM

供个人使用的 macOS 小说与剧本杀创作工作台。当前为 **0.1 桌面初版**，面向 Apple Silicon。

## 打开

在 Finder 中打开 `release/mac-arm64/JZRM.app`。构建脚本会为 App 做本机临时签名并校验包体；它没有 Apple Developer ID 签名或公证。首次遇到 macOS 安全提示时，可右键 App 选择“打开”。

## 已实现

- 作品库、卷章编辑、阅读、灵感泡泡、角色起名器、作品拆解与文风仓库。每部作品有独立的大纲、设定、记忆、细纲、正文分级页面，切换作品时资料一起切换。
- 全局助手、聊天室式脑暴和画布式创作流程提示。脑暴支持议题清单、参会 Agent、讨论轮数、逐轮继续、用户发言、历史记录和垃圾箱恢复。
- AI 配置分为 API 接入、生图模型、面宝、Prompt 模板、AI 用量；供应商下管理模型与密钥，可绑定创作、评审、辅助、拆书等职责。密钥交给 macOS Keychain 保存。支持 OpenAI 兼容、Anthropic Messages 和 Gemini 文本协议。
- Agent 技能树、Skill 导入、六种初始文风包。作品拆解可输入网址或关键词联网搜索来源并用已配置模型总结；前四种热点文风包可按需联网刷新。联网检索依赖本机 `mcporter` 的 Exa 配置，网址读取走 Jina Reader。
- 剧本杀改编工作区：角色第二人称视角、时间线冲突检查、线索与组织者手册编辑。审查修改：整体与局部审校、七维评分结构、三版修改提案。AI 润笔：续写、去人机味、逻辑对齐、情绪、心理、环境、动作、反转爽点、节奏伏笔、对话和文风等单项强化。三个工作区均可额外导入文件。
- 作品设定中的人物关系、地图、时间线可调用已配置的 OpenAI 兼容生图接口生成示意图；图片保存在本机作品资料中。
- TXT、DOCX、PDF 导出；TXT、Markdown、DOCX、PDF 导入；本地 JSON 备份与恢复。分类垃圾箱支持找回和永久删除。
- 设置页含使用说明、日间米白灰与夜间黑银主题、固定记忆区和上下文压缩长度。

## 当前边界

文本生成、联网蒸馏与生图都需要你自己的供应商模型与可用密钥。联网搜索还需要本机 Exa 搜索工具；未配置时会显示错误。生图目前按 OpenAI 兼容图片接口实现，其他生图协议需另接适配器。模型调用没有使用你的额度做端到端测试；首次使用建议先用短文本与一张图验证供应商配置。长篇剧本杀批量改写仍需真实材料逐步检验。

## 从源码启动

需要 Node.js 20 以上。运行 `npm install`、`npm run dev` 用浏览器预览；运行 `npm run start` 打开 Electron；运行 `npm test` 和 `npm run pack:mac` 验证与构建。Electron 的密钥保存、原生导入导出与联网检索仅在桌面窗口可用。

产品设计与 StarWriter 页面调研记录在 `docs/`。JZRM 是独立实现，未读取或复用 StarWriter 的源码与模型密钥。
