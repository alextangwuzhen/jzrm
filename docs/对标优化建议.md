# JZRM 对标 AI 写作助手优化建议

日期：内测01 第2轮。调研对象：Sudowrite、墨灵小说（InkSpire）、termo.ai open-novel-writing、StarWriter、彩云小梦等公开 AI 写作助手。

## 一、各家优点提炼

| 产品 | 核心优点 | 可迁移点 |
| --- | --- | --- |
| **Sudowrite** | Story Bible：Braindump→Synopsis→Characters→Worldbuilding→Outline→Scenes→Prose 逐级生成，每级有"生成/改写"按钮，且**明确每个字段受谁影响、影响谁**；**Match My Style** 从样例文本提取文风 | ① 设定生成做成**有依赖关系的流水线**，而非平铺卡片；② "从样例提取文风"一键反推 |
| **墨灵小说 InkSpire** | 剧情画布/章节画布（**AI 必须遵守，不是参考**）；万物百科（长期记忆自动注入，百万字不漂移）；真相记忆（伏笔/人物状态追踪）；拆书逐槽位+一键风格包；创世台五步 | ③ 大纲/细纲升级为**画布硬约束**；④ 作品资料做**结构化长期记忆**（已部分有）；⑤ 伏笔追踪已对齐 |
| **open-novel-writing** | 5 角色加权评审；章节 Spec（before/after state、tension_curve、must_happen、new_hooks）；连贯性检查；P0/P1 红线；分级评分 | ⑥ 已落地多角色评审+红线+档位；⑦ 补 **Spec 驱动创作**（每章先定目标/钩子/前后状态再写） |
| **StarWriter** | 情绪曲线、角色出场统计、关系图谱、发布审查（七维可配置）、朱雀七维、沉浸式评审+定位 | ⑧ 可视化图表（情绪曲线/出场/关系）是最大观感差距 |
| **彩云小梦** | 续写/润色/扩写单点任务、交互式续写 | ⑨ 已对齐（AI 润笔单点任务台） |

## 二、按优先级优化建议

### P0（高价值、低成本）
1. **角色出场统计** ✅ 已落地：审查修改新增「角色出场」Tab，按姓名统计每章出现次数 + CSS 条形图 + 明细表。
2. **情绪曲线**：每章 AI 返回「情绪倾向 + 强烈度」，画简单折线/柱状，标注节奏断裂（相邻强烈度骤变）。用 CSS/SVG 即可，不必引入 ECharts。
3. **关系图谱可视化**：已有 SVG 关系图（结构化关系已接入），补**交互**（悬浮高亮、拖拽）即可拉开观感。

### P1（中价值）
4. **Spec 驱动创作**：正文页写章前先填"本章目标 / 要埋钩子 / 人物前后状态 / 要回收伏笔"，生成正文时作为硬约束注入（对齐 open-novel-writing 的章节 Spec）。
5. **Match My Style**：文风仓库新增"从样例文本提取文风"——粘贴一段样例，AI 反推句长/对话比例/描写密度/语气，生成文风包。
6. **设定生成流水线**：新增"一键从灵感生成设定"，按 Braindump→Synopsis→角色→世界观→大纲 顺序逐级生成，每级可改可重生成（对齐 Sudowrite Story Bible）。
7. **发布审查（整书级）**：独立于章节评审的整书质量审查（文风/时间线/伏笔/节奏/商业/编辑视角 七维可增删，对齐 StarWriter）。

### P2（长期）
8. **万物百科式长期记忆**：作品资料按词条结构化存储，AI 调用时按相关性检索注入（而非全量截断），支撑百万字。
9. **写作数据分析**：字数/章节/时段趋势、热力图、连载进度（对齐 StarWriter 写作分析）。
10. **云同步/多端**：本地为主，可选导出/导入云端。

## 三、本轮已落地 vs 待办

- 已落地：多角色加权评审、档位、红线、连贯性检查、角色出场统计、拆书逐槽位、读者模拟三 Agent、改编接 Agent/Skill/文风、关系图读结构化关系。
- 建议下一步优先：**情绪曲线 + 关系图谱交互 + Spec 驱动创作**，这三项最直接对标 StarWriter/Sudowrite 的观感与写作一致性。
