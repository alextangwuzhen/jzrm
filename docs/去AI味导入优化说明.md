# 导入同事文本 · 去AI味 操作说明

目标：把同事创作的剧本杀剧本或小说文本导入，去掉"AI 味"，且**结果可验证、可回退**。

## 一、简单三步（好看懂）

1. **导入**：打开「AI 润笔」→ 右上「导入作品文件」（TXT/DOCX/PDF），或在正文页新建章节粘贴。导入不会覆盖原作品章节。
2. **去AI味**：强化任务选「去人机味」→ 可选加载「限制词/句式/语义/情景」四类限制 → 点「生成润笔提案」→ 预览差异后「替换原文」。
3. **复核**：切到「审查修改 → 朱雀AI检测」选该章节 → 「开始检测」，看内部 AI 率是否下降。

## 二、怎么"保证优化的结果"

- **先测后改再测**：改前跑一次朱雀检测记下 AI 率，改后再跑一次，确认下降；若未下降，点「润笔历史」恢复原文重试（可调整限制词多选）。
- **红线必杀**：润笔页多选 P0 红线（"不是……而是……"、段尾总结、感悟式结尾等）作为硬约束，改写时强制避开。
- **可回退**：每次「替换原文」都会自动保存"修改前"版本快照；替换结果都是先预览、再确认，不会悄悄覆盖。
- **不把估算当真**：朱雀 AI 率是内部估算，只用于提示可编辑痕迹，不能当作者身份鉴定；以"具体套话/模板化句子被删掉"为实际验收标准。

## 三、还能提升的地方（建议）

1. **批量去AI味**：目前逐章处理；可加"整书批量去AI味"，勾选多章一键跑，逐章预览确认。
2. **改动高亮对比**：预览时用 diff 高亮"删了哪些套话、改了什么"，一眼看清改动（比整段替换更直观）。
3. **同事剧本优先走逆向解析**：剧本杀剧本先走「改编 → 导入剧本杀剧本解析」，拆成角色本/线索/手册后再去 AI 味，比整篇硬改更保结构。
4. **自定义红线库**：把团队内部公认的 AI 味表达沉淀成自己的限制词/句式预设，复用给后续导入。
5. **导出对比报告**：导出去AI味前后 + 朱雀检测结果的报告，方便交付给同事核对。

## 四、结论

JZRM 已经具备"导入→去AI味→复核"的完整闭环，且结果可验证（朱雀前后对比）、可回退（版本快照）。后续若要"批量 + 更直观"，优先做第 1、2 条（批量去AI味 + 改动高亮对比）。
