# StarWriter 页面与操作链路核对记录

日期：2026-09-30。核对方式：在用户机器上的 StarWriter 桌面端及其本地界面逐页进入、点击分类和操作入口；用一个临时样本作品检查只有进入作品后才出现的页面。本文只记录实际看见的界面与行为。

## 一、全局入口

| 一级入口 | 已点开的页面与可见操作 | JZRM 决策 |
| --- | --- | --- |
| 首页 | 继续编辑最近作品、今日目标、连续创作、总作品与总字数、导入小说、新建作品 | 保留概况和快捷入口；增加当前创作流程建议 |
| 作品库 | 搜索作品；作品卡可编辑封面、编辑资料、删除、继续写作、进设定、进评审；新建作品 | 保留卡片逻辑；删除改为移入垃圾箱 |
| 阅读空间 | 全部/我的作品/用户上传筛选、搜索、导入、作品轮播、开始阅读 | 保留，并支持剧本杀角色视角筛选 |
| 作品拆解 | 搜索系列或书名、新建拆书任务；导入 TXT，按系列和单书组织报告 | 保留并扩展搜索、文风蒸馏、文风仓库 |
| 灵感泡泡 | 全部/开书想法/剧情/角色设定/角色名称/世界观/其他分类页；搜索、新建、随机灵感、灵感骰子 | 保留分类导航与卡片编辑，并可关联作品资料 |
| 角色起名器 | 自由起名、选小说换名两页；题材/性别/身份/简介/方案数/候选数；随机填充和全书换名 | 保留，换名先预览涉及的正文与设定 |
| 个人小说宇宙 | 像素宇宙、小说人物、故事与地点；选作品、AI 提炼人物和地点 | 入口替换为小说改编剧本杀 |
| 写作分析 | 字数、章节、写作时段、趋势、热力图、作品进度 | 入口替换为审查修改 |
| 成就系统 | 里程碑与勋章页 | 入口替换为 AI 润笔 |
| AI 配置 | API 接入、生图模型、星轨 AI 助手、Prompt 模板、AI 用量五个分级页 | 保留对应管理能力，Agent 配置扩展 |
| 移动配对 | 后端地址、配对码、已配对设备 | 入口替换为 Agent 技能树 |

全局还有 Cmd+K 搜索工作台、主题配色、明暗模式、个人资料。JZRM 保留这些全局交互，加上右上角助手、脑暴、流程提示和垃圾箱。

## 二、作品建立到写作

1. 首页或作品库新建：手动建书填写题材、状态、简介、字数目标和标签；另一条路径是 AI 问答建书。导入小说也是独立入口。
2. 进入某作品后，左栏首先是「写作」，其下有可展开的「设定」「分析与发布」「其他」和独立「朱雀AI检测」。这些是作品内的页面层级，并非全局一级菜单。
3. 写作页左侧为卷章目录，可新建卷、在卷内加章、批量操作；中间编辑卷引言或章正文，富文本工具含加粗、斜体、下划线、标题、列表；右侧为星轨 AI 面板。章节可自动保存、沉浸写作、使用设定创作或对话助手。全局小说创作可批量生成章节，并提示检查逻辑漂移。
4. 目录节点可编辑与删除。原应用的删除提示为不可恢复，JZRM 改为统一软删除与垃圾箱恢复。

## 三、作品内「设定」的全部分级页

| 页面 | 页面内进一步操作与用途 |
| --- | --- |
| 设定概览 | 查看世界观、角色、时间线、大纲、伏笔、文风等资料的入口与完成情况，导出设定集 |
| 世界观 | 概览、势力网络、力量体系、法则、地点地图、社会结构、异能体系、科技等级、经济体系、文化风俗十个分类；各类有添加/编辑/AI 识别或 AI 填充；概览有题材推荐卡、管理设定和自建设定 |
| 世界地图 | 可视化地点与连接；添加地点、连接、拖拽、缩放、背景生成、AI 识别 |
| 大纲 | 卷纲→章纲→场景树；AI 助手、批量创作、批量删除、添加卷纲、节奏控制；节点可编辑与删除 |
| 角色 | 分类、合并分类、搜索、添加角色、AI 填充；角色字段涵盖名字、别名、年龄、身份、外貌、性格、背景、说话习惯、角色弧光等 |
| 时间线 | 添加事件/AI 填充；按时间节点整理故事事实 |
| 伏笔追踪 | 添加/AI 填充；埋设、揭示、废弃状态与回收率，按状态筛选 |
| 属性面板 | 主角信息与立绘；属性、背包、技能树三个分级视图，支持通读全文识别、编辑、AI 生图/上传 |
| 文风 | 文风预设、句长、对话比例、描写密度、文风定位、要素、示例段落、写作原则；手动编辑或 AI 填充 |
| 历史版本 | 手动保存带备注的设定版本；约 30 秒无改动触发自动快照，页面标示最多保留 20 个自动版本 |

世界观十个分类均已点击。势力为关系网络；力量体系为等级轴；法则为规则清单；地点地图复用地图画布；社会结构为阶层金字塔；异能体系为能力雷达；科技等级为发展进度；经济体系为流动图；文化风俗为事件集。空状态也有明确的添加动作。

## 四、作品内「分析与发布」「其他」与阅读

| 页面 | 可见操作与用途 |
| --- | --- |
| 章节评审 | 逐章 AI 评审表，列综合评分、AI 痕迹、摘要和评审按钮 |
| 读者模拟 | 勾选章节，按小白读者、老书虫、编辑视角分别模拟反馈 |
| 发布审查 | 文风、AI 感、时间线、伏笔、节奏、商业、编辑视角共七项可选维度，可新增或重置维度 |
| 角色出场 | 根据角色资料查看出场；样本无角色时显示前置条件 |
| 情绪曲线 | 按章分析情绪值、强烈度与节奏断裂 |
| 关系图谱 | 角色关系网络；至少两名角色后才能推断或手动添加 |
| 导出作品 | 小说正文 TXT/Markdown/EPUB，设定集 HTML |
| 导入设定 | 下载模板→上传文件→智能分析→校对确认→导入完成；模板分 16 类，支持 TXT/DOCX/PDF/MD/JSON/YAML |
| 版本快照 | 选择章节，保存和管理正文历史版本 |
| 朱雀AI检测 | 选择章节后给七维特征诊断与修改建议；页面宣称的“AI 率”只是应用内部估算，不宜当成作者身份鉴定 |

阅读器实际进入过章节：左侧目录，中间正文与章节切换，右侧人物/地点；顶部有朗读、视觉插槽和阅读设置。阅读设置可调字号、字体、行高、背景、朗读声音与语速。

## 五、全局工具的次级操作

- 灵感泡泡新建有类别选择和富文本编辑；随机灵感可选题材；灵感骰子可摇角色、冲突、场景、反转等并锁定部分结果继续摇。
- 角色起名器的「选小说换名」分选作品与角色、头脑风暴、全书替换的步骤。
- 作品拆解新任务要求 TXT 文本，系列报告可追加书；尚未拿到成功的 AI 拆解报告。
- AI 配置中的「星轨AI助手」含记忆总开关、技能装载、规则与约束、个人规则、已沉淀记忆、会话记录；技能有导入、新建等入口。Prompt 模板页按创作辅助、评审检查、分析工具、自定义筛选，13 张预置卡有预览、编辑、复制、删除。模型页有识别本地模型入口；AI 用量页在无调用时为空状态。
- 作品库的删除是永久删除提示，这正是 JZRM 必须补垃圾箱的原因。

## 六、DeterminFlow 借用的三条交互

- 对话：会话列表、模型选择、输入框和工作区上下文。JZRM 将其做为全局「助手」弹窗，可携带参数跳转页面。
- 圆桌：创建表单有主题、固定轮询/智能主持、讨论轮次、上下文压缩和 2 至 6 个席位；席位可填角色名、主持状态、温度和角色 Prompt。JZRM 改称「脑暴」。
- 工作流：模板、脚本库、任务历史；模板进入后先是只读画布，再点编辑，节点库可拖 Agent、审批、脚本、子流程及各类网关，连线和变量可管理。JZRM 取画布编辑与流程引导逻辑，节点主要对应创作页面与辅助任务。

## 七、补充模型实测与重复功能整理

用户配置模型后，已在 StarWriter 点「测试」验证评审模型连接成功，并在六字的虚构样本章运行一次 AI 章节评审。结果页实际显示全书雷达图、综合分、六个分项、设定偏离、AI 痕迹、原文证据、建议，以及可编辑的章节正文。说明 StarWriter 已有「逐章评分＋证据＋修改建议」能力，JZRM 不再另造平行的章节评审数据。JZRM 在同一审校记录之上增加用户要求的七维量表、《剑来》90 分标尺、导入对比对象、整篇修改计划、局部三案替换和 DOCX/PDF/TXT 导出。

这个样本只有「测试文字。」；StarWriter 仍给出 3.5/10 综合分，同时在文字中承认材料不足。JZRM 应在正文太短或必要事实缺失时显示「材料不足」并列出缺口，不产生误导性的精确综合分。

另外三处重叠要共用数据与执行入口：AI 润笔和正文编辑器里的续写/润色用同一任务记录；Agent 技能树是 AI 配置中 Agent 的可视化管理视图；文风仓库中的包被作品文风页引用，不能复制一份失联的参数。全局助手取代原星轨对话入口，脑暴复用 Agent 实例；主管 Agent 给流程节点推荐执行者，流程画布负责步骤和依赖。

## 八、实际核对边界

本次逐页进入了全部一级入口、作品内全部可见分级页、世界观十个分类和阅读器。评审结果页已由真实模型调用核验。拆书任务的文件选择器在浏览器自动化中没有正常弹出，尚未拿到成功拆解后的报告；空角色条件下的角色出场图和关系图谱完整状态也未核验。JZRM 对这些结果页按用户功能需求自行设计，实施时做真实任务测试，不声称已复制到原应用全部结果态。

样本作品「JZRM 功能调研临时样本」用于进入作品页。原应用删除为不可恢复操作，当前保留，待用户明确确认删除后清理。
